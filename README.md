**Rocket AI Assistant** is an AI-powered software designed for calculating suborbital rocket flight trajectories and analyzing telemetry data. This project aims to automate engineering calculations for amateur rocketry projects (300-400m altitude range).

### 🔗 [Live Demo App](https://ghostyengine-arhitect-ctgd7mzrakyna7kbzfrdag.streamlit.app/)

---

## ⚡ Key Features
* **Trajectory Calculation:** Precise modeling of flight path and peak altitude (apogee).
* **AI Analysis:** Automated detection of flight anomalies and performance predictions.
* **Data Visualization:** Real-time interactive charts for velocity, altitude, and acceleration.
* **Export Data:** Ability to save calculation results for further engineering review.

## 🛠 Tech Stack
* **Language:** Python 3.x
* **UI Framework:** Streamlit
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-learn (if applicable)
